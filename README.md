### Snake And Apple

## Description
This is a snake and apple game made by me. In this game your supposed to control your snake and try to eat the apples in the screen and every apple is 1 extra growth for the snake and it also increases your score by 1 every time you eat an apple and crashing into walls end the game and there will be a retry button to try the game again!
